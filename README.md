# Gabriel Rosa Arcangelo — Portfolio

Personal portfolio website built with Vite + React + TypeScript, Tailwind CSS and shadcn/ui.

## Requirements

- Node.js 18+
- npm

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## What technologies are used for this project?

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
